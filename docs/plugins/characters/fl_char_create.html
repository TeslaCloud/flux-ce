    PANEL:next_stage()

    client plugins/characters/plugin/views/cl_character_creation.lua:210

    Validates the current stage and moves on to the next one. On the last stage it asks for confirmation and sends the character creation request to the server. Does nothing while the server has not responded to a creation request that was already sent.

    Returns

    • Boolean false when validation failed or a request is pending, otherwise nil
