    add_filter(id, data)
    Stores a message filter under the specified id. Serverside only. Filters are only stored at the moment, nothing reads them yet.
    add_text(listeners, ...)
    Builds a chat message from the arguments and sends it to the listeners that can hear it. Serverside only. Strings are displayed as text, numbers set the font size of the following text, colors set its color, players and entities are displayed by their names. Tables with is_data = true are displayed as icons or images. Any other table is merged into the message options: sender, position, radius (0 is global), size, should_translate.
    can_hear(listener, message_data)
    Checks whether the listener should receive the message. Serverside only. The PlayerCanHear hook can force a message through. Otherwise a radius of 0 reaches every initialized player, a negative radius reaches nobody, and a positive radius reaches the players whose eyes are within it from the position of the message.
    compile(msg_table)
    Converts a message that was received from the server into a list of pieces with calculated sizes and positions, ready to be drawn by a fl_chat_message panel. Strings are wrapped to the width of the chatbox. Clientside only.
    create()
    Creates the chatbox panel in its closed state, taking the size and position from the current theme. The panel is stored in Chatbox.panel.
    hide()
    Closes the chatbox, disables its mouse and keyboard input and runs the ChatTextChanged hook with an empty string.
    message_to_string(message_data, concatenator)
    Joins the strings of a message into a single string. Players and entities are replaced with their names, numbers and other values are skipped.
    player_say(actor, text, team_chat)
    Makes the player say the text in the chat, by default to all players. Runs the PlayerSay hook first, which may change or suppress the text. The icon and colors come from the ChatboxGetPlayerIcon, ChatboxGetPlayerColor and ChatboxGetMessageColor hooks, and the ChatboxAdjustPlayerSay hook can alter the finished message. Serverside only.
    set_client_mode(val) internal
    Toggles the mode in which Chatbox.add_text displays every table instead of merging tables into the message options. Enabled while relaying chat.AddText of a client.
    show()
    Opens the chatbox, creating its panel first if necessary. Does nothing if there is no panel and the theme has not been initialized yet.

    Chatbox.add_text(listeners, ...)

    plugins/chatbox/plugin/sv_plugin.lua:84

    Builds a chat message from the arguments and sends it to the listeners that can hear it. Serverside only. Strings are displayed as text, numbers set the font size of the following text, colors set its color, players and entities are displayed by their names. Tables with is_data = true are displayed as icons or images. Any other table is merged into the message options: sender, position, radius (0 is global), size, should_translate.

    -- Message for everyone.
Chatbox.add_text(nil, Color(255, 200, 0), 'The server restarts in 5 minutes!')

-- Message from a player that is heard within 300 units of them.
Chatbox.add_text(nil,
  { icon = 'fa-shield-alt', size = 14, margin = 8, is_data = true },
  team.GetColor(actor:Team()), actor, Color(255, 255, 255), ': ', text,
  { sender = actor, position = actor:GetPos(), radius = 300 }
)

-- Message for certain players only.
Chatbox.add_text(Bolt:get_staff(), Color(234, 255, 208), '@staff ', actor, ': ', text)

    Parameters

    • listeners List<Player>/Player the receivers, nil to send to all players
    • ... Vararg pieces of the message and option tables

    See also

    • Chatbox.can_hear

    Chatbox.player_say(actor, text, team_chat)

    plugins/chatbox/plugin/sv_plugin.lua:198

    Makes the player say the text in the chat, by default to all players. Runs the PlayerSay hook first, which may change or suppress the text. The icon and colors come from the ChatboxGetPlayerIcon, ChatboxGetPlayerColor and ChatboxGetMessageColor hooks, and the ChatboxAdjustPlayerSay hook can alter the finished message. Serverside only.

    • team_chat Boolean optional, defaults to nil whether the message was sent to the team chat
