    fl_chat_message object

    PANEL

    Part of chatbox

    Summary

    Methods

    eject()
    Removes the message from the chatbox history and deletes its panel, unless the ShouldMessageeject hook returns false.
    Init()
    Records when the message was added and when it should start to fade out.
    Paint(w, h)
    Draws the texts, images and icons of the compiled message, unless the ChatboxPrePaintMessage hook returns true.
    set_message(msg_info)
    Sets the compiled message to display and resizes the panel to its height. Does nothing if the chatbox panel does not exist.
    Think()
    Updates the visibility and opacity of the message: fully visible while the chatbox is open, dimmed while a command is being typed, fading out after the fade delay.
