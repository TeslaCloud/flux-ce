    Registers a hint that Hints:display_random can pick.

    Picks a random registered hint and shows it as a notification for 15 seconds. Nothing is shown if the picked hint has a callback that does not return true.

    • color Color optional, defaults to nil text color of the notification
    • play_sound Boolean optional, defaults to false play a blip sound when the hint is displayed
    • callback Function optional, defaults to nil called without arguments when the hint is picked; the hint is only shown if it returns true
