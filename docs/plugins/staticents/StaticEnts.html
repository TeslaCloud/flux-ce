    StaticEnts hooks

    Plugin hooks and methods

    Part of staticents

    Summary

    Methods

    InitPostEntity()
    Runs the PersistenceLoad hook once the map's entities have been created.
    load_class(ent_class)
    Spawns the saved static entities of one class and marks them as persistent. Does nothing if there is no usable save for that class. Serverside only.
    PersistenceLoad()
    Loads the saved static entities of every whitelisted class.
    PersistenceSave()
    Saves every persistent entity to the plugin data of the current schema and map, one 'static/<class>' entry per entity class. Runs the PrePersistenceSave hook first.
    PlayerMakeStatic(actor, is_static)
    Makes the entity the player is looking at static, or removes its static status, and notifies the player about the outcome. The entity's class has to be whitelisted and the player needs the 'static' or 'unstatic' permission respectively.
    RegisterPermissions()
    Registers the 'static_tool' permission.
    SaveData()
    Runs the PersistenceSave hook whenever the framework saves its data.
    ShutDown()
    Runs the PersistenceSave hook when the server shuts down.
    whitelist_ent(ent_class)
    Allows entities of a class to be made static and to be loaded from the saves. Serverside only.
