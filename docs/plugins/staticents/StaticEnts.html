    Summary

    Hooks

    InitPostEntity()server
    Runs the PersistenceLoad hook once the map's entities have been created.
    PersistenceLoad()server
    Loads the saved static entities of every whitelisted class.
    PersistenceSave()server
    Saves every persistent entity to the plugin data of the current schema and map, one 'static/<class>' entry per entity class.
    PlayerMakeStatic(actor, is_static)server
    Makes the entity the player is looking at static, or removes its static status, and notifies the player about the outcome.
    RegisterPermissions()shared
    Registers the 'static_tool' permission.
    SaveData()server
    Runs the PersistenceSave hook whenever the framework saves its data.
    ShutDown()server
    Runs the PersistenceSave hook when the server shuts down.

    Methods

    load_class(ent_class)server
    Spawns the saved static entities of one class and marks them as persistent.
    whitelist_ent(ent_class)server
    Allows entities of a class to be made static and to be loaded from the saves.

    StaticEnts:PlayerMakeStatic(actor, is_static)

    server plugins/staticents/plugin/sv_hooks.lua:65

    Implements hook PlayerMakeStatic

    Makes the entity the player is looking at static, or removes its static status, and notifies the player about the outcome. The entity's class has to be whitelisted and the player needs the 'static' or 'unstatic' permission respectively.

    Parameters

    • actor Player
    • is_static Boolean true to make the entity static, false to make it unstatic
