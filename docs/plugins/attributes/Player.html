    Adds a temporary boost to the player's level in an attribute. The boost is stored on the character, networked, and removed by a timer when it expires. Server only.

    Parameters

    • attribute_id String attribute to boost; ignored when it is not boostable
    • value Number levels to add

    Player:multiply_attribute(attribute_id, value, duration)

    plugins/attributes/plugin/lib/sh_attributes.lua:409

    Adds a temporary progress multiplier to an attribute of the player. The multiplier is stored on the character and networked. Server only.

    -- Double strength progress for an hour.
target:multiply_attribute('strength', 2, 3600)

    Parameters

    • attribute_id String attribute to affect; ignored when multipliable is false
    • value Number multiplier, 2 doubles the progress gained
    • duration Number seconds until the multiplier expires

    See also

    • Player#get_attribute_multiplier

    Player:progress_attribute(attribute_id, amount, no_multiplier)

    plugins/attributes/plugin/lib/sh_attributes.lua:269

    Adds progress to an attribute, raising or lowering its level whenever a level threshold is crossed. Does nothing for attributes with has_progress set. Server only.

    -- Scaled by the player's multiplier when the attribute is multipliable.
target:progress_attribute('lockpicking', 15)
-- Always exactly 15.
target:progress_attribute('lockpicking', 15, true)

    Parameters

    • attribute_id String
    • amount Number progress to add, negative to remove
    • no_multiplier Boolean optional, defaults to false do not scale the amount by the player's multiplier
