    PANEL:create_selector(title, message, default_value, choices, callback)

    client plugins/conditions/plugin/views/cl_conditions.lua:241

    Opens a selector popup and calls the callback once for every choice right away, so that it can add the choice to the selector.

    parent:create_selector(data.name, 'condition.role.message', 'condition.roles',
  Bolt:get_roles(), function(selector, role)
    selector:add_choice(t(role.name), function()
      panel.data.role = role.id

      panel.update()
    end)
  end)

    Parameters

    • title String title phrase
    • message String message phrase
    • default_value String phrase of the text that is displayed before a choice is made
    • choices List/Map values to choose from
    • callback Function called as callback(selector, choice) for every choice

    Returns

    • Panel the created fl_selector panel
