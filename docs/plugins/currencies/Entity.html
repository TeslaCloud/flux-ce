    Summary

    Methods

    can_contain_money()
    Checks whether the entity is able to hold money by running the CanContainMoney hook.
    drop_money(currency, value)
    Drops money from a player as an fl_money entity where they are looking, at most 120 units away; if they look at another player the money is given to that player. Server only.
    get_money(currency)
    Returns how much of a currency the entity holds.
    give_money(currency, value)
    Adds money to the entity. Server only.
    give_money_to(target, currency, value)
    Moves money from this entity to another one if the CanGiveMoney hook allows it, and notifies the players involved. Server only.
    has_money(currency, value)
    Checks whether the entity holds at least the given amount of a currency.
    set_money(currency, value)
    Sets how much of a currency the entity holds, rounded to the currency's decimals and never below 0, networks it and runs the EntityMoneyChanged hook. Server only.
    take_money(currency, value)
    Removes money from the entity; the balance stops at 0. Server only.
