    Hooks

    LoadData()server
    Loads the stored 3D texts and pictures when the framework loads its data.

    Sends all stored 3D texts and pictures to the player who has just initialized.
    PostDrawOpaqueRenderables()client
    Draws every placed 3D text and picture within fade range of the local player, plus a placement preview while the texts or pictures tool is equipped.
    RegisterPermissions()shared
    Registers the 'texts' and 'pictures' level design permissions.

    Saves the 3D texts and pictures when the framework saves its data.

    SurfaceText:add_picture(data)

    server plugins/3dtexts/plugin/sh_plugin.lua:107

    Adds a 3D picture, saves it and broadcasts it to all clients. Serverside only. Does nothing unless url, width and height are all present.

    SurfaceText:add_picture({
  url         = 'https://example.com/poster.png',
  width       = 512,
  height      = 512,
  fade_offset = 0,
  pos         = trace.HitPos,
  normal      = trace.HitNormal,
  angle       = angle -- built the same way as for SurfaceText:add_text
})

    Parameters

    • data Map picture data: url, width, height, pos, normal, angle and optional fade_offset

    SurfaceText:add_text(data)

    server plugins/3dtexts/plugin/sh_plugin.lua:82

    Adds a 3D text, saves it and broadcasts it to all clients. Serverside only. Does nothing unless text, pos, angle, style and scale are all present.

    local trace = actor:GetEyeTrace()
local angle = trace.HitNormal:Angle()
angle:RotateAroundAxis(angle:Forward(), 90)
angle:RotateAroundAxis(angle:Right(), 270)

SurfaceText:add_text({
  text        = 'Sample Text',
  style       = 5,                      -- 1 to 10, see the texts tool
  scale       = 1,
  color       = Color(255, 255, 255),
  extra_color = Color(255, 0, 0, 100),  -- background / shadow color
  fade_offset = 0,
  pos         = trace.HitPos,
  normal      = trace.HitNormal,
  angle       = angle
})

    Parameters

    • data Map text data: text, style, scale, color, extra_color, pos, normal, angle and optional fade_offset
