    Stamina:start_running(target, prevent_drain)

    server plugins/stamina/plugin/sv_hooks.lua:123

    Pauses the player's stamina regeneration. Unless prevent_drain is set, it also runs the PlayerStartRunning hook on the server and on the player's client, and starts draining stamina every 0.2 seconds. Serverside only.

    Parameters

    • target Player
    • prevent_drain Boolean optional, defaults to false only pause the regeneration

    Stamina:stop_running(target, prevent_regen)

    server plugins/stamina/plugin/sv_hooks.lua:170

    Pauses the player's stamina drain. With prevent_regen set it runs the PlayerStopRunning hook on the server and on the player's client; without it, it starts regenerating stamina every 0.2 seconds instead. Serverside only.

    Parameters

    • target Player
    • prevent_regen Boolean optional, defaults to false do not start the regeneration
