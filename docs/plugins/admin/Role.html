    Role class

    Summary

    Methods

    allow(action, object, callback)
    Allows this role to perform an action, optionally only on one kind of object. If a callback is given, it decides the outcome of each check.
    allow_anything()
    Makes every permission check against this role pass.
    can(actor, action, object)
    Checks whether this role allows an action. Only the role's own permission table is consulted; use actor:can for the full check that includes per-player permissions.
    disallow(action, object)
    Explicitly denies an action for this role, overriding a permission inherited from its base.
    get_base()
    Returns the ID of the role this role is based on.
    get_color()
    Returns the role's color.
    get_description()
    Returns the role's description, usually a language phrase.
    get_icon()
    Returns the role's icon.
    get_id()
    Returns the role's ID.
    get_immunity()
    Returns the role's immunity level, which Bolt:check_immunity compares between roles.
    get_name()
    Returns the role's display name.
    get_permissions()
    Returns the role's permission table.
    init(id)
    Sets the role's ID and gives it an empty permission table. Does nothing without an ID.
    is_protected()
    Checks whether the role is flagged as protected.
    on_role_set(target, old_group)
    Called when the player's role is being set to this role. Return any non-nil value to keep the new role from being saved to the database.
    on_role_taken(target, new_group)
    Called when the player's role is taken or modified. Return any non-nil value to keep the new role from being saved to the database.
    register()
    Registers the role with Bolt. If the role has a define_permissions method, it is run first with the can, cannot and allow_anything globals temporarily bound to this role, followed by the OnDefinePermissions hook.

    Role:allow(action, object, callback)

    plugins/admin/plugin/lib/classes/sh_role.lua:34

    Allows this role to perform an action, optionally only on one kind of object. If a callback is given, it decides the outcome of each check.

    function ROLE:define_permissions()
  self:allow('kick')
  self:allow('noclip', nil, function(actor, object)
    return actor:Alive()
  end)
end

    Parameters

    • action String permission ID
    • object String/Map optional, defaults to 'anything' object name, or a class table whose class_name is used
    • callback Function optional, defaults to nil called as callback(actor, object) on every check; its return value becomes the result

    Role:register()

    plugins/admin/plugin/lib/classes/sh_role.lua:181

    Registers the role with Bolt. If the role has a define_permissions method, it is run first with the can, cannot and allow_anything globals temporarily bound to this role, followed by the OnDefinePermissions hook.

    -- roles/sh_helper.lua
ROLE.name = 'Helper'
ROLE.immunity = 50
ROLE.base = 'user'

function ROLE:define_permissions()
  can 'kick'
  cannot 'ban'
end
