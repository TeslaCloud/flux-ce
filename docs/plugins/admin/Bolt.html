    server plugins/admin/plugin/sv_hooks.lua:10

    Checks connecting players against the ban cache. A timed ban that passes the expiry check is lifted and the player let in; any other ban rejects the connection with its reason.

    Parameters

    • steam_id64 String 64-bit SteamID of the connecting player
    • ip String
    • sv_pass String server password
    • cl_pass String password entered by the client
    • name String player name

    Returns

    • Boolean true to allow or false to reject (nothing if there is no ban)
    • String rejection message (only when rejecting)

    Bolt:ban(target, duration, reason, prevent_kick)

    server plugins/admin/plugin/lib/sh_admin.lua:305

    Bans a player or a SteamID and saves the ban to the database. A player entity is also kicked, unless prevent_kick is set.

    -- Ban an online player for a day.
Bolt:ban(target, 60 * 60 * 24, 'Prop spam')
-- Permanently ban somebody by SteamID.
Bolt:ban('STEAM_0:1:12345', 0, 'Cheating')

    Parameters

    • target Player/String the player to ban, or a SteamID
    • duration Number optional, defaults to 0 ban length in seconds, 0 for a permanent ban
    • reason String optional, defaults to 'N/A'
    • prevent_kick Boolean optional, defaults to false do not kick the banned player

    Bolt:can(actor, action, object)

    shared plugins/admin/plugin/lib/sh_admin.lua:163

    Checks whether a player may perform an action. Unexpired temporary permissions are consulted first, then the player's own permissions, then the player's role; invalid players (such as the server console) and root players are always allowed.

    Parameters

    • actor Player
    • action String permission ID; an empty string is always allowed
    • object String optional, defaults to nil object name the permission was allowed for, passed on to Role#can

    Returns

    • Boolean whether the action is allowed (a role permission callback's return value is passed through as is)

    Bolt:interpret_ban_time(str)

    shared plugins/admin/plugin/lib/sh_admin.lua:406

    Converts a human-readable duration into seconds. Bare numbers are taken as minutes, and words such as 'perma' or 'forever' (as well as text with no recognizable duration) give 0, which bans treat as permanent.

    Bolt:interpret_ban_time(30)                  -- 1800
Bolt:interpret_ban_time('15')                -- 900
Bolt:interpret_ban_time('2 hours')           -- 7200
Bolt:interpret_ban_time('1 week 3 days')     -- 864000
Bolt:interpret_ban_time('couple of minutes') -- 120
Bolt:interpret_ban_time('perma')             -- 0

    Parameters

    • str String/Number duration text, or a number of minutes

    Returns

    • Number/Boolean duration in seconds, or false if str is neither a string nor a number

    Bolt:register_permission(id, name, description, category, role)

    shared plugins/admin/plugin/lib/sh_admin.lua:134

    Registers a permission that can then be checked with actor:can(id). Permissions registered before plugins finish loading (normally from a RegisterPermissions hook) are then allowed for the given role and for every role based on it.

    function Doors:RegisterPermissions()
  Bolt:register_permission('manage_doors', 'Doors settings access',
    'Grants access to customize doors.', 'permission.categories.level_design', 'assistant')
end

    Parameters

    • id String permission ID; nothing happens if it is empty or not a string
    • name String optional, defaults to id display name
    • description String optional, defaults to 'No description provided.'
    • category String optional, defaults to 'general' category name or language phrase
    • role String optional, defaults to nil ID of the role that is allowed this permission by default
