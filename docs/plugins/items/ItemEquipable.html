    Called by ItemEquipable:can_transfer before the item is equipped. Override it and return false to prevent the item from being equipped.

    Returns

    ItemEquipable:can_transfer(inventory, x, y)

    shared plugins/items/plugin/items/bases/sh_item_equipable.lua:34

    Called on the server by the 'CanItemTransfer' hook before the item is moved to another inventory. Prevents equipping the item if can_equip disallows it or its equipment slot is occupied, and prevents unequipping it if can_unequip disallows it.

    Parameters

    • inventory Inventory the inventory the item is being moved to
    • x Number target slot, or nil if the position is yet to be found
    • y Number target slot, or nil if the position is yet to be found

    Returns

    • Boolean false to prevent the transfer, nil otherwise

    ItemEquipable:equip(owner, should_equip)

    shared plugins/items/plugin/items/bases/sh_item_equipable.lua:100

    Applies or reverts the equipped state of the item; it does not move the item itself. Empties and disables (or enables back) the inventories listed in disabled_inventories, calls post_equipped or post_unequipped and runs the 'OnItemEquipped' or 'OnItemUnequipped' hook.

    Parameters

    • owner Player
    • should_equip Boolean true to equip the item, false to unequip it

    shared plugins/items/plugin/items/bases/sh_item_equipable.lua:158

    Called on the server when a player presses the equip button in the item's menu. Moves the item to its equipment inventory, or back to the main inventory if it is equipped already. An item lying in the world is picked up and equipped.
