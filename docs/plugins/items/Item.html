    Item.create(id, data, forced_id)

    shared plugins/items/plugin/lib/sh_item.lua:249

    Creates a new instance of an item template. On the server it also runs the 'OnItemCreated' hook, saves the items and sends the new instance to all clients.

    local item_obj = Item.create('test_item', { name = 'Some Item' })

if item_obj then
  Item.spawn(actor:GetEyeTraceNoCursor().HitPos, nil, item_obj)
end

    Parameters

    • id String item id of the template
    • data Map optional, defaults to nil fields to override on the new instance
    • forced_id Number optional, defaults to nil instance id to use instead of generating a new one

    Returns

    • Item the new instance, or nil if there is no such template

    Item.find(name)

    shared plugins/items/plugin/lib/sh_item.lua:202

    Finds an item by a loose query. A number is treated as an instance id. A string is compared against the template ids and matched as a Lua pattern against the template names and print names.

    Parameters

    • name String/Number item id or (part of) item name, or an instance id

    Returns

    • Item first matching template, or the instance for a number; nil if not found

    Item.spawn(position, angles, item_obj)

    server plugins/items/plugin/lib/sh_item.lua:500

    Spawns an item instance in the world as an fl_item entity. Server-side only. The item is sent to all clients and the item entities are saved afterward.

    local item_obj = Item.create('test_item')
local trace = actor:GetEyeTraceNoCursor()
local ent = Item.spawn(trace.HitPos, Angle(0, 0, 0), item_obj)

    Parameters

    • position Vector where to put the item; it is raised by the height of its bounds
    • angles Angle optional, defaults to nil
    • item_obj Item item instance; templates cannot be spawned

    Returns

    • Entity the item entity
    • Item the spawned item; nothing if the arguments are invalid
