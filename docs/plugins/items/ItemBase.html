    ItemBase:add_button(name, data)

    plugins/items/plugin/lib/classes/sh_item.lua:154

    Adds a custom button to the menu of the item.

    ITEM:add_button('item.option.open', {
  icon = 'icon16/briefcase.png',
  -- Calls ITEM:on_open(actor) on the server when the button is pressed.
  callback = 'on_open',
  -- Client-side. The button is hidden if this returns false.
  on_show = function(item_obj)
    return !IsValid(item_obj.entity)
  end
})

    Parameters

    • name String id of the button; also its title, unless data has name or get_name
    • data Map button data: icon (String), callback (String name of the item's method to call on the server), and optionally name (String) or the client-side functions get_name, get_icon, on_show and on_click, each of which receives the item

    ItemBase:do_menu_action(act, actor, ...)

    plugins/items/plugin/lib/classes/sh_item.lua:261

    Performs a menu action on the item on behalf of the player. Runs the 'PlayerCanUseItem' hook and then the hook of the action ('PlayerTakeItem', 'PlayerUseItem' or 'PlayerDropItem'). Every action except 'on_use' and 'on_take' also calls the item's method of the same name with the player and the extra arguments. Runs the 'PlayerUsedItem' hook when done.

    -- Makes the player pick up the item into their hotbar.
item_obj:do_menu_action('on_take', actor, { inv_type = 'hotbar' })

    Parameters

    • act String 'on_use', 'on_take', 'on_drop' or the callback of a custom button
    • actor Player the player performing the action
    • ... Vararg extra arguments that are passed to the hooks and to the item's method
