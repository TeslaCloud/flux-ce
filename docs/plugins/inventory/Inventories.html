    PreItemTransfer(item_obj, new_inventory, old_inventory)
    Calls the on_transfer callback of the item before it changes its inventory.
    SaveCharacterData(owner, char)
    Stores the instance ids of the player's items in the character, as a comma-separated string.
    spawnmenu_populate_items(content_panel, tree, node)
    Fills the items tab of the spawn menu with a node for every item category.
