    draw.stenciled(draw_func, stencil_func)

    client packages/flow/core/cl_core.lua:278

    Draws with a cutout: whatever draw_func draws is only visible outside of the area that stencil_func draws. Does nothing unless both arguments are functions.

    -- A 2 pixel wide frame: the outer box minus the inner box.
draw.stenciled(function()
  draw.RoundedBox(0, x, y, w, h, color)
end, function()
  draw.RoundedBox(0, x + 2, y + 2, w - 4, h - 4, color)
end)

    Parameters

    • draw_func Function draws the visible contents; called without arguments
    • stencil_func Function draws the area to cut out; its output is not shown
