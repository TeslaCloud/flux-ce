    surface.draw_circle_outline_partial(percentage, x, y, radius, thickness, passes)

    packages/flow/core/cl_core.lua:249

    Draws a part of a ring in the current surface draw color, starting at the top and going clockwise. Uses the stencil buffer.

    Parameters

    • percentage Number how much of the ring to draw, from 0 to 100
    • x Number screen x of the center
    • y Number screen y of the center
    • radius Number outer radius
    • thickness Number optional, defaults to 1 width of the ring in pixels
    • passes Number optional, defaults to 360 amount of segments a full circle would have
