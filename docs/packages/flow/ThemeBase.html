    ThemeBase:add_panel(id, callback)

    client packages/flow/lib/classes/cl_theme.lua:49

    Registers a callback that creates a panel for this theme. This lets themes replace the panels that are created with Theme.create_panel.

    self:add_panel('tab_menu', function(id, parent, ...)
  return vgui.Create('fl_tab_menu', parent)
end)

    Parameters

    • id String panel ID
    • callback Function receives the panel ID, the parent panel and any extra arguments, must return the created panel

    ThemeBase:register_asset(name, path, options)

    client packages/flow/lib/classes/cl_theme.lua:76

    Registers an asset of the theme. Models are precached, images (PNG and JPEG) are stored as theme materials. When sizes are specified, the smallest scale that covers the height of the screen relative to 720p is picked, and the image is loaded from the file with the '_<scale>x' suffix instead.

    -- On a 1080p screen this loads 'materials/flux/gradient_2x.png'.
self:register_asset('gradient', 'materials/flux/gradient.png', { sizes = { 1, 2, 4 } })

    Parameters

    • name String key to store the material under
    • path String path to the asset
    • options Map optional, defaults to {} sizes: List<Number> of available image scales, in ascending order

    Returns

    • Material the stored material, nil if the asset is not an image

    ThemeBase:set_font(key, value, scale, data)

    client packages/flow/lib/classes/cl_theme.lua:122

    Sets a font of the theme. The font is derived from an existing one with Font.size.

    self:set_font('text_bar', 'flRoboto', math.scale(17), { weight = 600 })

    Parameters

    • key String
    • value String name of an existing font to base this one on
    • scale Number optional, defaults to nil font size, the base font is used as is if omitted
    • data Map optional, defaults to nil extra font data to override in the sized font

    Returns

    • String name of the font that has been set
