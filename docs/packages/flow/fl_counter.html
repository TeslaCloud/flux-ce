    fl_counter object

    PANEL

    Part of Flow

    Summary

    Methods

    check_buttons()
    Disables the increase button while the value is at the maximum and the decrease button while it is at the minimum, and enables them otherwise.
    decrease()
    Decreases the value by one, clamped to the configured range. Calls on_click first and leaves the value unchanged if it returns false; calls post_click afterward.
    get_value()
    Returns the current value of the counter.
    increase()
    Increases the value by one, clamped to the configured range. Calls on_click first and leaves the value unchanged if it returns false; calls post_click afterward.
    Init()
    Creates the title label and the increase and decrease buttons.
    on_click(value)
    Called before the value changes when one of the buttons is clicked. Does nothing by default; override it to react to the change, and return false from it to reject the change.
    Paint(w, h)
    Draws the current value in the middle of the counter.
    PerformLayout(w, h)
    Positions the label and both buttons and refreshes the enabled state of the buttons.
    post_click()
    Called after a button click has changed the value. Does nothing by default; meant to be overridden.
    set_color(color)
    Sets the color of the title and the value.
    set_font(font)
    Sets the font of the title and the value.
    set_max(max)
    Sets the highest value the counter can reach.
    set_min(min)
    Sets the lowest value the counter can reach.
    set_min_max(min, max)
    Sets both the lowest and the highest value the counter can reach.
    set_text(text)
    Sets the title shown above the counter.
    set_value(value)
    Sets the current value. The value is not clamped and on_click is not called.
