    Player:play_gesture(animation)

    shared packages/flow/lib/sh_animation.lua:437

    Plays a gesture on top of the player's regular animations in the custom gesture slot. Called serverside, the gesture is sent to every client through the animation event system, so this is the way to make everyone see a one-off animation such as a punch, a wave or a weapon draw.

    Parameters

    • animation Number activity (ACT_ enum) or String sequence name

    Returns

    • Boolean false if the player's model has no such sequence

    Player:restore_player()

    server packages/flow/lib/meta/sv_player.lua:84

    Loads the database record of the player by their SteamID, creating and saving a new one if they have joined for the first time. The query is asynchronous: the record is put into self.record and the 'PlayerRestored' hook is run once it has loaded. Bots get a blank record that is never saved here.
