    Log:write(message, action, object, subject, io)

    shared packages/flow/models/log.lua:15

    Records a log entry. On the server the entry is saved to the logs table. The entry is also remembered so that it can be passed on with Log:replicate.

    Parameters

    • message String text of the entry
    • action String optional, defaults to nil type of the logged event; stored in snake_case
    • object String/Number optional, defaults to nil who or what performed the action, e.g. a user ID
    • subject String/Number optional, defaults to nil who or what the action was performed on
    • io Function optional, defaults to nil outputs the entry; called with (message, action in CamelCase, object, subject)
