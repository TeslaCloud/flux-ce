    Flux.Undo class

    Part of Flow

    Summary

    Methods

    add(callback, ...)
    Adds a function to call when the current undo entry is undone.
    create(id, name)
    Starts a new undo entry. Add callbacks to it with Flux.Undo#add, assign it to a player and finish it to put it into the undo queue of that player.
    do_player(owner)
    Undoes the most recent entry in the undo queue of a player and removes it from the queue.
    execute(obj)
    Calls all of the callbacks of an undo entry.
    finish()
    Puts the current undo entry on top of its player's undo queue. The entry is discarded if it has no valid player.
    get_player(owner)
    Returns the undo queue of a player.
    remove(owner, id)
    Removes the undo entries with the specified ID from the undo queue of a player.
    set_player(owner)
    Sets the player that the current undo entry belongs to.
