    Methods

    bodygroups()
    Returns the current values of all of the entity's bodygroups.
    facing(entity)
    Checks whether the yaw angles this entity and the specified one are aiming at differ by more than 50 degrees. Both must be able to aim (players or NPCs).
    freeze()
    Freezes the entity and marks it as frozen with the 'fl_frozen' networked variable. Players are unable to move and to use their active weapon, NPCs are put to sleep. Runs the 'EntityFreeze' hook afterward. Meant to be called on the server.
    get_hitgroup_from_pos(pos)
    Finds the hitbox of the entity that contains the specified position.
    get_name()
    Returns the display name of the entity. Players use the 'GetPlayerName' hook and their name, everything else uses the 'GetEntityName' hook and its string representation.
    idle_animation()
    Finds an idle sequence of the entity's model.
    is_door()
    Checks whether the entity is a door, judging by its class and model.
    is_frozen()
    Checks whether the entity has been frozen with Entity#freeze.
    set_bodygroups(bodygroups)
    Sets several bodygroups of the entity at once.
    stuck()
    Checks whether the bounding box of the entity intersects the world or another entity.
    unfreeze()
    Unfreezes the entity that was frozen with Entity#freeze. Runs the 'EntityUnfreeze' hook afterward. Meant to be called on the server.
