    Theme.hook(id, ...)

    client packages/flow/lib/cl_theme.lua:63

    Calls a method of the active theme in protected mode. Errors are printed to the console instead of being raised. Also available as Theme.call.

    function PANEL:Paint(w, h)
  Theme.hook('PaintButton', self, w, h)
end

    Parameters

    • id String name of the theme method
    • ... Vararg arguments to pass to the method

    Returns

    • Any everything the method has returned; nil if there is no active theme, it has no such method or the method has failed

    Theme.load_theme(theme_id, reloading)

    client packages/flow/lib/cl_theme.lua:232

    Makes the specified theme the active one. Calls on_loaded of every theme it derives from and of the theme itself, applies its Derma skin, and runs the 'OnThemeLoaded' hook. Unless reloading, it can be prevented with the 'ShouldThemeLoad' hook.

    Parameters

    • theme_id String ID of a registered theme
    • reloading Boolean optional, defaults to false skips the 'ShouldThemeLoad' hook and the theme's own on_loaded
