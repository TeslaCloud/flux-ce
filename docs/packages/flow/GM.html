Flux v0.8.1

    GM hooks

    Gamemode hooks

    Part of Flow

    Summary

    Hooks

    AddDeathNotice()
    Does nothing, so that the default death notices are never added.
    AddTabMenuItems(menu)
    Adds the scoreboard and help items to the tab menu.
    AllowPlayerPickup(actor, entity)
    Prevents players from picking entities up with the use key.
    CalcMainActivity(actor, velocity)
    Picks the base activity of a player (idle, walking or running) and updates their move_yaw pose parameter. An animation forced with Player#set_animation takes priority.
    CanPlayerSuicide(actor)
    Prevents players from killing themselves through the console.
    ContextMenuOpen()
    Creates the context menu if the local player has the context_menu permission and removes it if they do not.
    DoAnimationEvent(actor, event, data)
    Plays the attack and reload gestures and handles the jump and reload cancel events.
    DoPlayerDeath(victim, attacker, damage_info)
    Does nothing, which disables the default handling of a player's death.
    DrawDeathNotice()
    Does nothing, which removes the default death notices from the HUD.
    DrawPlayerTargetID(target, x, y, distance)
    Collects the target ID lines of a player through the GetDrawPlayerInfo hook and draws them in order of priority, fading out between 500 and 640 units of distance. Nothing is drawn if the PreDrawPlayerInfo hook returns false.
    EntityRemoved(entity)
    Clears the networked variables of the removed entity before passing the event on to the base gamemode.
    EntityTakeDamage(ent, damage_info)
    Runs the PlayerTakeDamage hook when the damaged entity is a player.
    FLHUDPaint(cur_time, scrw, scrh)
    Draws the circular action progress indicator in the middle of the screen if a percentage was set with Flux.set_circle_percent.
    FLSaveData()
    Saves the config and runs the SaveData hook.
    FluxClientSchemaLoaded()
    Creates the fonts once the schema has been loaded on the client.
    FluxPackageLoaded()
    Writes the files that get sent to clients (shared data, settings, language phrases and the HTML, CSS and JavaScript assets) into lua/_flux/client.
    ForceDermaSkin()
    Makes Derma use the Flux skin by default.
    GetDrawPlayerInfo(target, x, y, distance, lines)
    Adds the name of the player to the lines shown in their target ID.
    GetFallDamage(actor, speed)
    Returns the fall damage of a player: the result of the FLGetFallDamage hook if it returns one, otherwise a value calculated from the fall speed.
    GetGameDescription()
    Returns the gamemode name shown in the server browser: name_override if it is a string, otherwise 'FL - ' followed by the schema name.
    GrabEarAnimation()
    Does nothing, which disables the default ear grab animation while chatting.
    HUDAmmoPickedUp(item_name, amount)
    Does nothing, which disables the default ammo pickup notification.
    HUDDrawPickupHistory()
    Does nothing, which disables the default pickup history on the HUD.
    HUDDrawScoreBoard()
    Draws the loading screen with its status text and progress bar while the local player is not initialized yet or the ShouldDrawLoadingScreen hook returns true.
    HUDDrawTargetID()
    Finds the entity the local player is looking at, or the one closest to the crosshair within a narrow cone, and draws its target ID through the DrawPlayerTargetID hook, the entity's own DrawTargetID method or the DrawEntityTargetID hook.
    HUDItemPickedUp(item_name)
    Does nothing, which disables the default item pickup notification.
    HUDPaint()
    Draws the Flux HUD once the local player is initialized: the damage flash, the death screen while dead or the info displays while alive (unless FLHUDPaint returns a truthy value), and the white respawn fade. Skipped when the ShouldHUDPaint hook returns false.
    HUDPaintDeathBackground(cur_time, w, h)
    Draws the red blood overlay behind the death screen.
    HUDShouldDraw(element)
    Hides the default HUD elements that Flux replaces, such as health, armor, ammo, the crosshair and the damage indicators.
    Initialize()
    Removes unused sandbox hooks and, on the server, imports the configuration from the settings, loads the config, connects to the database and registers the Discord webhooks. Runs the FLInitialize hook when done.
    InitPostEntity()
    Stores the local player in the PLAYER global, sends the client's language to the server, reports to the server that the player has been created and runs the client-side loading hooks (PlayerModelChanged for every player, SynchronizeTools, LoadData, FLInitPostEntity).
    InitPostEntity()
    Registers the Flux tools with the tool gun and runs the LoadData and FLInitPostEntity hooks.
    MouthMoveAnimation()
    Does nothing, which disables the default mouth movement while using voice chat.
    OnConfigSet(key, old_value, new_value)
    Applies changes of the walk_speed, run_speed, crouched_speed and jump_power configs to every player.
    OneSecond()
    Runs the FLSaveData hook every data_save_interval seconds, unless FLShouldSaveData returns false. Also checks every half an hour whether the server is empty and reloads the map if it is, unless ShouldServerAutoRestart returns false.
    OnIntroPanelCreated()
    Flashes the game window in the taskbar when the intro panel appears.
    OnMenuPanelOpen(menu_panel, active_panel)
    Centers a newly opened panel within the tab menu.
    OnPhysgunFreeze(weapon, phys_obj, entity, actor)
    Lets the base gamemode freeze the entity if the player has the physgun_freeze permission.
    OnReloaded()
    After a Lua refresh, registers the Flux tools with the tool gun again and, in development, reapplies the animation table of every player.
    OnReloaded()
    Writes the files that get sent to clients again after a Lua refresh.
    OnResolutionChanged(old_w, old_h, new_w, new_h)
    Recreates the fonts so that they fit the new resolution. Note that GM:Tick runs this hook with the new size first, so the values received are the reverse of what the parameter names say.
    PhysgunPickup(actor, entity)
    Lets players with the physgun_pickup permission pick entities up with the physics gun.
    PlayerBindPress(client, bind, pressed)
    Intercepts the undo bind and blocks it when the SoftUndo hook returns a value.
    PlayerDeath(victim, inflictor, attacker)
    Stores the time at which the player may respawn, based on the respawn_delay config.
    PlayerDeathSound(victim)
    Mutes the default death sound.
    PlayerDeathThink(actor)
    Respawns a dead player once their respawn time has passed.
    PlayerDisconnected(actor)
    Saves the data of the player unless their should_save_data field is false, tells all clients about the disconnect and logs it.
    PlayerGiveSWEP(actor, weapon, swep)
    Decides whether a player may give themselves a weapon. Requires the spawn_sweps permission and that the FLPlayerGiveSWEP hook does not return false. Invalid players are always allowed.
    PlayerInitialized()
    Rebuilds the spawn menu and the tool menu once the server has initialized the local player.
    PlayerInitialized(actor)
    Marks the player as initialized and, shortly after, runs PlayerInitialized on their client.
    PlayerInitialSpawn(actor)
    Sets up a newly connected player: assigns the flux_player class and the 'user' group, restores their saved data and announces the spawn to all clients. Bots are marked as initialized right away instead.
    PlayerModelChanged(target, new_model, old_model)
    Assigns the animation table of the new model to the player and, on the client, disables inverse kinematics for them. Does nothing if no new model is given.
    PlayerNoClip(actor, state)
    Decides whether a player may toggle noclip by asking the plugins through the PlayerEnterNoclip and PlayerExitNoclip hooks. Allowed if no plugin returns a value.
    PlayerOneSecond(actor, cur_time)
    Runs the PlayerPositionChanged hook if the player has moved since the previous check.
    PlayerSay(actor, text, team_chat)
    Passes chat messages that start with a command prefix to the command interpreter and hides them from the chat.
    PlayerSetModel(actor)
    Sets the model of a player. A string returned by the PrePlayerSetModel hook is used as the model, and false defers to the base gamemode. Otherwise bots and initialized players get the model from their 'model' networked variable (a citizen model if it is not set), and anyone else is left to the base gamemode.
    PlayerShouldTakeDamage(victim, attacker)
    Asks the FLPlayerShouldTakeDamage hook whether a player can be damaged. Note that a false or nil result of the hook is turned into true, so damage is never blocked here.
    PlayerSpawn(actor)
    Resets the state of a spawning player (model, collisions, visibility and the movement speeds from the config), runs the PostPlayerSpawn hook and creates their hands model.
    PlayerSpawnEffect(actor, model)
    Decides whether a player may spawn an effect. Requires the spawn_entities permission and that the FLPlayerSpawnEffect hook does not return false. Invalid players are always allowed.
    PlayerSpawnNPC(actor, npc, weapon)
    Decides whether a player may spawn an NPC. Requires the spawn_npcs permission and that the FLPlayerSpawnNPC hook does not return false. Invalid players are always allowed.
    PlayerSpawnObject(actor, model, skin)
    Decides whether a player may spawn a prop, ragdoll or effect. Requires the spawn_entities permission and that the FLPlayerSpawnObject hook does not return false. Invalid players are always allowed.
    PlayerSpawnProp(actor, model)
    Decides whether a player may spawn a prop. Requires the spawn_props permission and that the FLPlayerSpawnProp hook does not return false. Invalid players are always allowed.
    PlayerSpawnRagdoll(actor, model)
    Decides whether a player may spawn a ragdoll. Requires the spawn_ragdolls permission and that the FLPlayerSpawnRagdoll hook does not return false. Invalid players are always allowed.
    PlayerSpawnSENT(actor, class)
    Decides whether a player may spawn a scripted entity. Requires the spawn_entities permission and that the FLPlayerSpawnSENT hook does not return false. Invalid players are always allowed.
    PlayerSpawnSWEP(actor, weapon, swep)
    Decides whether a player may spawn a weapon. Requires the spawn_sweps permission and that the FLPlayerSpawnSWEP hook does not return false. Invalid players are always allowed.
    PlayerSpawnVehicle(actor, model, name, tab)
    Decides whether a player may spawn a vehicle. Requires the spawn_vehicles permission and that the FLPlayerSpawnVehicle hook does not return false. Invalid players are always allowed.
    PlayerTakeDamage(victim, damage_info)
    Notifies the client of the damaged player, which shows the damage flash on their HUD.
    PlayerThink(actor, cur_time)
    Runs the current action of the player, unless it is 'idle' or 'spawning'.
    PlayerUse(activator, target)
    Tells the client of the player to open the interaction menu for the player or entity they pressed the use key on, at most once a second.
    PopulateToolMenu()
    Adds every registered Flux tool to the tool list of the spawn menu, then runs the SynchronizeTools hook.
    PostPlayerLoadout(actor, default_loadout)
    Strips the weapons of the player, gives them the default loadout and selects the first weapon of it.
    PostPlayerSpawn(actor)
    Gives the player their loadout, plus the tool gun and the physics gun if they have the toolgun and physgun permissions, then runs PostPlayerSpawn on their client.
    PreLoadPlugins()
    Loads the list of disabled plugins into Flux.shared before the plugins are loaded.
    RenderScreenspaceEffects()
    Updates the blurred copy of the screen used by draw.blur_box and draw.blur_panel. Only does so while something has requested the blur, and no more often than the blur update interval unless Flux.blur_update_fps is 0.
    ScoreboardHide()
    Closes the tab menu when the scoreboard key is released after being held for longer than 0.3 seconds, unless the ShouldScoreboardHide hook returns false. A short press leaves the menu open.
    ScoreboardShow()
    Opens the tab menu in place of the default scoreboard, closing the previous one first, unless the ShouldScoreboardShow hook returns false.
    ServerRestart()
    Saves the data of every player before the server restarts.
    ShowHelp(actor)
    Does nothing, which disables the default help menu.
    SoftUndo(client)
    Asks the server to undo the last Flux undo entry of the local player.
    SpawnlistContentChanged()
    Removes the sandbox hint timer about saving spawnlists.
    SpawnMenuOpen()
    Removes the sandbox hint timers and allows the spawn menu to open.
    SynchronizeTools()
    Copies every registered Flux tool into the tool table of the tool gun.
    Think()
    Updates the global UI offset from the rotation of the local player's view, so that HUD elements using it sway and settle back. Skipped while the player is frozen.
    Tick()
    Checks once a second whether the screen resolution has changed and runs the OnResolutionChanged hook if it has.
    Tick()
    Runs the PlayerThink hook for every player eight times a second and the PlayerOneSecond hook once a second.
    TranslateActivity(actor, act)
    Translates an activity into the animation that the Flux animation tables define for the player's model, weapon hold type or vehicle. Models without an animation table are handled by the base gamemode.
