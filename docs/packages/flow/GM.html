    GM:CalcMainActivity(actor, velocity)

    shared packages/flow/hooks/sh_hooks.lua:126

    Picks the base activity of a player (idle, walking or running), updates their move_yaw pose parameter and plays the landing gesture when they touch the ground. An animation forced with Player#set_animation takes priority. The run threshold comes from the animation table and has a small hysteresis so that the animation does not flicker when moving at about that speed.

    Parameters

    • actor Player
    • velocity Vector velocity of the player

    Returns

    • Number activity (ACT_ enum, or -1 for a forced animation)
    • Number sequence to play instead of the activity, or -1 for none
