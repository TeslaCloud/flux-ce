    Saves a table to 'settings/flux/' in the game folder as JSON. The '.json' extension is added if the key does not have one. Does nothing unless the value is a table.
    save(key, value)
    Saves a table to the 'flux' folder inside the client's 'data' folder as JSON. The '.dat' extension is added if the key does not have one. Does nothing unless the value is a table.
    save_plugin(key, value)
    Saves plugin data. It is stored separately for every schema and map.
    save_schema(key, value)
    Saves a table to the data folder of the current schema and map.
