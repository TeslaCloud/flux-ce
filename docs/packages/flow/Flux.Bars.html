    Summary

    Methods

    adjust(id, data)
    Merges the specified settings into an existing bar.
    draw(id)
    Draws the bar with the specified ID using the active theme. Does nothing if the bar does not exist or the 'ShouldDrawBar' hook rejects it.
    DrawTopBars()
    Draws every bar from the prioritized list of top bars.
    get(id)
    Returns the bar registered under the specified ID.
    hinder_value(id, new_value)
    Sets the hindrance value of a bar (the part of it that is blocked off), clamped between 0 and its max value. Calls the 'PreBarHinderValueSet' theme hook first.
    position()
    Recalculates the positions of all top bars, stacking them vertically in order of priority. Plugins can offset each bar through the 'AdjustBarPos' hook.
    prioritize()
    Rebuilds the list of top bars grouped by priority. Bars rejected by the 'ShouldDrawBar' hook are left out.
    register(id, data, force)
    Registers a HUD bar. If a bar with this ID already exists it is returned untouched, unless force is set or Flux runs in development mode.
    set_value(id, new_value)
    Sets the value of a bar, clamped between 0 and its max value, and starts the fill animation toward it. Calls the 'PreBarValueSet' theme hook first.

    Flux.Bars:register(id, data, force)

    packages/flow/lib/cl_bars.lua:35

    Registers a HUD bar. If a bar with this ID already exists it is returned untouched, unless force is set or Flux runs in development mode.

    Flux.Bars:register('getup', {
  text = t'ui.hud.bar_text.getup',
  color = Color(50, 200, 50),
  max_value = 100,
  x = ScrW() * 0.5 - Flux.Bars.default_w * 0.5,
  y = ScrH() * 0.5 - 8,
  height = 20,
  type = BAR_MANUAL
})

    Parameters

    • id String unique bar ID
    • data Map bar settings such as text, color, value, max_value, x, y, width, height, priority, type (BAR_TOP, BAR_MANUAL or BAR_HIDDEN), font and callback (receives the bar, returns its new value); missing keys get defaults
    • force Boolean optional, defaults to false overwrite an existing bar with the same ID

    Returns

    • Map the stored bar, or nil if no data was given
