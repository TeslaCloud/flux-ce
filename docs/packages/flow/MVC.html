    MVC.handler(name, handler)

    server packages/flow/lib/sh_mvc.lua:94

    Registers a function that handles the requests clients send with MVC.push or MVC.request. Call respond_to inside the handler to send a response back. Serverside only.

    MVC.handler('fl_create_character', function(actor, data)
  local status = Characters.create(actor, data)

  respond_to { success = status == CHAR_SUCCESS, status = status }
end)

    Parameters

    • name String name of the request
    • handler Function receives the player who has sent the request, followed by the request's data
