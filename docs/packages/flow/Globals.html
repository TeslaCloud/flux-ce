    t(phrase, args, force_lang)

    shared packages/flow/lib/sh_lang.lua:41

    Translates a phrase to the current language. English is used if the language is not available, and the phrase itself is returned if it has no translation. Line breaks in the result are replaced with spaces.

    local text = t'ui.char_create.unknown_error'
-- Replaces {name} in the translated phrase.
local message = t('ui.char_create.delete_confirm_msg', { name = self.char_data.name })

    Parameters

    • phrase String phrase ID with its nesting separated by dots, or plain text
    • args Map/Any optional, defaults to nil values to replace the {key} placeholders with, by key; a single value replaces {1}
    • force_lang String optional, defaults to nil language code to use instead of the current language

    Returns

    • String translated text
    • Number amount of line breaks that were replaced
