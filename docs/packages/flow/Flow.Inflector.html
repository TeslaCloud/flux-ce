    Flow.Inflector:inflections(lang, func)

    shared packages/flow/lib/inflector/sh_inflector.lua:23

    Defines the inflection rules of a language. The rules added inside of the callback (and anything looked up afterward) belong to that language.

    Flow.Inflector:inflections('en', function(inflect)
  inflect:plural(i'^(ox)$', '%1en')
  inflect:singular(i'(quiz)zes$', '%1')
  inflect:irregular('person', 'people')
  inflect:uncountable(w'data ammo equipment')
end)

    Parameters

    • lang String language code
    • func Function receives the inflector

    Returns

    • Flow::Inflector self, for chaining
