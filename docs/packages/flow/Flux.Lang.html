    Flux.Lang:add(index, value, reference)

    packages/flow/lib/sh_lang.lua:73

    Adds a phrase, or a table of phrases that is merged into the existing ones recursively.

    -- Makes t'my_plugin.greeting' available in English.
Flux.Lang:add('en', {
  my_plugin = {
    greeting = 'Hello, {name}!'
  }
})

    Parameters

    • index String language code, or the key of the phrase inside the reference table
    • value String/Map phrase or a nested table of phrases
    • reference Map optional, defaults to nil table to add to, all stored phrases by default
