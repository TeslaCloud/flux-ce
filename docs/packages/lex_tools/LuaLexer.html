    LuaLexer:tokenize(source, extended)

    packages/lex_tools/lib/lua_lex.lua:101

    Converts Lua (GLua) source code into a list of tokens.

    local tokens = LuaLexer:tokenize('local a = 1')

for k, v in ipairs(tokens) do
  print(LuaLexer:visualize(v.tk), v.val, v.line)
end
-- TK_local   local   1
-- TK_name    a       1
-- =          =       1
-- TK_number  1       1

    Parameters

    • source String source code
    • extended Boolean optional, defaults to false also emit tokens for spaces, tabs, semicolons and newlines

    Returns

    • List<Map> tokens with the fields tk (token type), val (text), line and pos; false if source is nil
