    ActiveRecord.Adapters.Abstract:raw_query(query, callback, query_type, bindings)

    shared packages/active_record/lib/adapters/abstract.lua:168

    Sends a raw SQL string to the database. Does nothing in the abstract adapter. Values are best kept out of the SQL itself and passed as bindings instead, which take the place of the #placeholder of the adapter in the query and need no escaping.

    Parameters

    • query String SQL to run
    • callback Function optional, defaults to nil called with the result rows, the query string and the time the query took in seconds
    • query_type String optional, defaults to nil lowercase query type, e.g. 'select' or 'insert'
    • bindings List optional, defaults to nil values of the bind parameters of the query, in the order of their placeholders; strings, numbers and booleans are supported. A query that is given bindings has to be a single statement
