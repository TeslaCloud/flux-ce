    ActiveRecord.Base class

    Part of Active Record

    ActiveRecord.Base:where(condition, ...)

    shared packages/active_record/lib/base.lua:105

    Specifies a WHERE condition in the query. The values are passed to the database as bind parameters, so they need no escaping.

    Object:where('column', 'value')
Object:where('column > ?', 100)
Object:where({ ['column'] = 'value', ['column2'] = { 'value', 'value2' } })

    Parameters

    • condition String/Map column name, SQL condition (which may use ? placeholders), or a hash of column-value pairs in which a List value stands for IN (...)
    • ... Vararg value to compare the column with, or the values that replace the ? placeholders

    ActiveRecord.Base:has(what, many)

    shared packages/active_record/lib/base.lua:676

    Specifies that the object has one or many of another object. The object(s) will be stored in a field with the same name as the child's database table.

    MyClass:has('users', true)
...
MyClass:first():expect(function(obj)
  print(obj.users) -- table
end)

    Parameters

    • what String/Map table name of the child model, or a hash such as { 'table_name', as = 'field_name' } to store the object(s) in another field
    • many Boolean true if the object has many of them, false if it has only one

    Returns

    • ActiveRecord::Base(self)
