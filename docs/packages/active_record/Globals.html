    Adds a column to an existing table.

    add_column('users', 'role', 'string', { default = '\'user\'' })
add_column('users', { 'banned', type = 'boolean', default = false })

    Parameters

    • table_name String table name
    • name String/Map column name, or a table holding the name at index 1, the abstract column type under 'type' and the options as keys
    • type String optional, defaults to nil abstract column type, e.g. 'string', 'integer' or 'datetime'
    • options Map optional, defaults to nil null (Boolean) and default (inserted into the SQL as is)

    add_index(table_name, columns, options)

    packages/active_record/lib/helpers.lua:192

    Creates an index. The index is named '<table>_<columns>_index' if no name is given.

    add_index('users', 'steam_id')
add_index('characters', { 'user_id', 'name' }, { unique = true })
add_index { 'users', 'steam_id', unique = true }

    Parameters

    • table_name String/Map table name, or a table holding the table name at index 1, the column(s) at index 2 and the options as keys
    • columns String/List<String> optional, defaults to nil column name or a list of column names
    • options Map optional, defaults to nil name, unique, length, using, where and if_not_exists

    create_table(name, options, callback)

    packages/active_record/lib/helpers.lua:82

    Creates a database table. The 'id' primary key is added automatically.

    create_table('logs', function(t)
  t:text 'body'
  t:string { 'action', null = false }
  t:timestamps()
end)

create_table('users', { force = true }, function(t) ... end)

    Parameters

    • name String table name
    • options Map optional, defaults to nil force (drop an existing table first), if_not_exists (leave an existing table alone), id (false to not add a primary key), primary_key (name of the primary key column, 'id' by default)
    • callback Function optional, defaults to nil receives the 'create' ActiveRecord::Query to define the columns on
