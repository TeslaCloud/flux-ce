    Adds a column to the ORDER BY clause.

    query:order('id')              -- ORDER BY id ASC

    • key String/Map column name (sorted in ascending order), or a hash with the column name stored under the 'asc' or 'desc' key

    ActiveRecord.Query:where_raw(condition, values)

    shared packages/active_record/lib/database/query.lua:121

    Adds a raw SQL condition. Nothing in it is escaped or quoted.

    query:where_raw('money > 100')
query:where_raw('money > ? AND name != ?', { 100, 'John' })

    Parameters

    • condition String SQL condition
    • values List optional, defaults to nil values that are bound in place of the ? placeholders in the condition. Without it the question marks in the condition are left as they are
