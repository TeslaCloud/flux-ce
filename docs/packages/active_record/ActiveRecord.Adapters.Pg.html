    ActiveRecord.Adapters.Pg:raw_query(query, callback, query_type, bindings)

    shared packages/active_record/lib/adapters/pg.lua:124

    Runs a raw SQL query on the PostgreSQL server. In sync mode this blocks until the query is done; without a connection the query is put into the queue instead.

    Parameters

    • query String SQL to run
    • callback Function optional, defaults to nil called with the result rows (a List of row Maps), the query string and the time the query took in seconds
    • query_type String optional, defaults to nil unused
    • bindings List optional, defaults to nil values of $1, $2 and so on in the query. A query that is given bindings has to be a single statement

    Returns

    • Any whatever the callback returns in sync mode, nothing otherwise
