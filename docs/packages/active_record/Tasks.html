    after_migration(executed)
    Refreshes the models and regenerates the schema file once migrations have run.
    context()
    Returns the migration context of the active schema, creating it if needed.
    forward(steps)
    Runs the next pending migrations (flux db:forward STEP=n).
    import_metadata_version()
    Records the migrations as run for a database whose newest migration version is stored under the 'version' key of the 'ar_metadata' table, with nothing in the 'ar_schema_migrations' table. Every migration file up to that version is considered run, the key is deleted, and the indexes and foreign keys of a schema file that holds a 'Structure' object are imported into the metadata.
    import_structure_metadata(metadata)
    Imports the metadata (indexes, references and primary keys) of a schema file that holds a 'Structure' object.
    migrate(version)
    Runs the pending migrations, or migrates to a version (flux db:migrate VERSION=x).
    migrate_down(version)
    Reverts a single migration (flux db:migrate:down VERSION=x).
    migrate_status()
    Prints the status of every migration (flux db:migrate:status).
    migrate_up(version)
    Runs a single migration (flux db:migrate:up VERSION=x).
    names()
    Returns the names of the console tasks.
    prepare()
    Brings the database up to date when the server starts: installs the migrations of the packages and plugins, loads the schema file into a fresh database and runs the pending migrations.
    redo(steps, version)
    Reverts and re-runs migrations (flux db:migrate:redo STEP=n or VERSION=x).
    rollback(steps)
    Reverts the newest migrations (flux db:rollback STEP=n).
    run(name, env)
    Runs a task by its console name, e.g. 'migrate:status', with the adapter in sync mode. Errors are printed instead of raised.
    schema_dump()
    Writes the current schema into the schema file (flux db:schema:dump).
    schema_load()
    Loads the schema file, which creates the tables it describes and records its version and every older migration as run (flux db:schema:load).
    schema_path()
    Returns the path of the schema file, relative to the game folder.
    structure_schema_file()
    Checks whether the schema file holds a 'Structure' object (the one-argument form of ActiveRecord.Schema:define). Such a file cannot be loaded.
    version()
    Prints the current schema version (flux db:version).
