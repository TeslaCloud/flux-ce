    ActiveRecord.Adapters.Mysqloo:raw_query(query, callback, query_type, bindings)

    packages/active_record/lib/adapters/mysqloo.lua:120

    Runs a raw SQL query on the MySQL server. In sync mode this blocks until the query is done; without a connection the query is put into the queue instead. A query that is given bindings is run as a prepared statement.

    Parameters

    • query String SQL to run
    • callback Function optional, defaults to nil called with the result rows (a List of row Maps), the query string and the time the query took in seconds. For 'insert' queries the result is a single row with the id of the new row instead
    • query_type String optional, defaults to nil lowercase query type, e.g. 'insert'
    • bindings List optional, defaults to nil values of the ? placeholders in the query. A query that is given bindings has to be a single statement

    Returns

    • Any whatever the callback returns in sync mode, nothing otherwise
