    string.find_all(str, pattern)

    shared lib/stdlib/sh_string.lua:159

    Finds all occurrences of a pattern in a string.

    local hits = string.find_all('{data:rank} {callback:get_name}', '{([%w_]+):([%w_]+)}')
-- hits[1] = { text = '{data:rank}', start_pos = 1, end_pos = 11, matches = { 'data', 'rank' } }

    Parameters

    • str String string to search in
    • pattern String Lua pattern to search for

    Returns

    • List<Map> a hash with the text, start_pos, end_pos and matches (captures) keys for every occurrence, or nil if str or pattern is missing

    string.fmt(format, data)

    shared lib/stdlib/sh_string.lua:474

    Replaces the {name} placeholders in a string with the values from a hash. Placeholders that have no value are removed.

    Parameters

    • format String text with placeholders made of letters, digits and underscores
    • data Map optional, defaults to {} placeholder name => String/Number value

    Returns

    • String the formatted string
    • Number amount of placeholders that were replaced

    string.parse_parent(str, ref)

    shared lib/stdlib/sh_string.lua:411

    Follows a ::-separated path for as long as it points to existing tables. Returns the last table it reached and the name to look up or create in it.

    -- While Flux exists and Flux.Thing does not:
local parent, name = ('Flux::Thing'):parse_parent() -- Flux, 'Thing'
local parent, name = ('Thing'):parse_parent()       -- _G, 'Thing'

    Parameters

    • str String path to the table
    • ref Map optional, defaults to _G table to start the lookup from

    Returns

    • Map the last existing table on the path
    • String the first part of the path that is not a table (the last part if the whole path already exists)
