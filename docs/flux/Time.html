    Time class

    The DateTime class represents a time interval, not a point in time. For points in time, please use Date or DateTime.

    Time:format_nice(suffix, from_now, amt, lang)

    shared lib/stdlib/sh_time.lua:213

    Same as nice, but performs formatting. Takes the three values that nice returns and translates them into readable text.

    local text = Time:format_nice(Time:minutes(5):nice()) -- e.g. '5 minutes from now'

    Parameters

    • suffix String time phrase, as returned by nice
    • from_now String 'time.from_now' or 'time.ago' phrase or an empty string, as returned by nice
    • amt Number amount of time, as returned by nice
    • lang String optional, defaults to current language language to translate to

    Returns

    • String phrases
