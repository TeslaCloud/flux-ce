    class(name, parent_class)

    lib/stdlib/sh_class.lua:37

    Creates a new class. Supports constructors and inheritance. The class is stored in the global table, or inside of another table when the name is namespaced with ::. Every class gets a new function that creates an instance and calls its init constructor, and an include method that mixes a module into the class.

    class 'Animal'

function Animal:init(name)
  self.name = name
end

class 'Dog' extends 'Animal'

function Dog:init(name)
  super(name) -- calls Animal's constructor on the new object
end

Dog:include 'Talkable' -- copies missing methods from the Talkable module

local dog = Dog.new('Rex')

    Parameters

    • name String class name in ConstantStyle, may be namespaced (e.g. 'ActiveRecord::Model')
    • parent_class String/Map optional, defaults to nil base class or its name

    Returns

    • Map the created class

    See also

    • extends
    • mod

    Color(r, g, b, a)

    lib/stdlib/sh_color.lua:221

    Creates a color. Replaces the built-in Color function to also accept hexadecimal strings and CSS color names.

    Color(255, 165, 0)
Color('#ffa500')
Color('orange')
Color('orange', 100) -- orange with the alpha of 100

    Variants

    • Color(r, g, b, a)
      • r Number red, 0-255
      • g Number green, 0-255
      • b Number blue, 0-255
      • a Number optional, defaults to 255 alpha, 0-255
    • Color(r)
      • r String hexadecimal color that starts with '#'
    • Color(r, g)
      • r String CSS color name such as 'orange', case-insensitive
      • g Number optional, defaults to 255 alpha, 0-255

    Returns

    • Color the created color, white if the string is not a known color name

    See also

    • util.hex_to_color
