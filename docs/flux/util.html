    util.wait_for_ent(ent_index, callback, delay, wait_time)

    Calls the callback as soon as the entity with the given index becomes valid, right away if it already is. Useful on the client, where an entity index can arrive before the entity itself does. Gives up without calling the callback once it runs out of attempts.

  hook.Run('PlayerModelChanged', target, new_model, old_model)
end)

    Parameters

    • ent_index Number entity index
    • callback Function callback(entity), receives the valid Entity
    • delay Number optional, defaults to 0 seconds between the attempts
    • wait_time Number optional, defaults to 100 maximum amount of attempts
