    abort()
    Aborts the current pipeline action. To be handled by callbacks individually.
    find(id)
    Find a pipeline with a specified ID. Case-sensitive.
    include(pipe, file_name)
    Include a filename using a specified pipeline. This automatically resolves server/client/shared realms, and automatically extracts the ID based on the filename (for example, "sh_test_file.lua" becomes "test_file" in the ID). After that if the pipe is a valid registered pipeline, the callback is called.
    include_folder(id, directory)
    Include all files in a folder using a specific pipeline. See documentation for Pipeline.include.
    is_aborted()
    Checks if the current pipeline has been aborted.
    register(id, callback)
    Registers a new pipeline with the specified ID and callback. The callback is called for every file included through the pipeline. It receives the ID extracted from the file name, the path of the file and the pipeline's data table.
